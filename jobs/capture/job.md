# capture — `kgme capture` (HANDOFF-0050)

**Purpose.** The vault fills from what Michou says, not from what he types. An agent that hears him state a reminder, a task, a friction, or a note runs this with his words verbatim and shows him what it printed (`CLAUDE.md`, "How decisions are made").

**Invocation.** `kgme capture <remind|task|friction|note|daily> "<his words>" [--due <when>]`, or `uv run python jobs/capture/run.py` with the same arguments. By hand or by an agent in a session; never scheduled.

**What it writes.** `remind`, `task`, `note`: a new file under `memory/notes/`, named from the first words (kebab-case, `-2` and on when taken), rendered from `memory/templates/reminder.md`, `task.md`, or `note.md`: the template's keys in its order and its defaults, with a ULID `id`, `created` and `modified` now, `source: stated`, `author: kgme`, his words as the `#` title. `--due` is read in `kgme.toml` `[brief] timezone` and written ISO 8601 with its offset: today, tomorrow, a weekday (the next one; today only while its time is ahead), `2026-10-20`, `oct 20`, `in 3 days`, `in 2 weeks`, each with an optional time (`9am`, `9:30pm`, `14:00`, `noon`; 09:00 when none), or a time alone (its next occurrence). `next friday` and `this friday` are refused as ambiguous; a passed instant is refused; a reminder without `--due` is refused. `friction`: one line appended to `memory/inbox/friction-log.md`, `- YYYY-MM-DD HH:MM — <his words>`. `daily`: `- <his words>` appended under the closing `## Michou` heading of `memory/daily/<today>.md` (the heading added first when the note does not end under it); before the day's note exists, the line is held verbatim in the ledger and `kgme daily` writes it into the draft.

**What it never does.** Edit or delete a file, create the friction log, or write a line break: a capture is one line. Every byte already in a file it adds a line to is unchanged: the file is replaced whole, by itself plus the line (a temp file named `.<name>.capture-<intent id>`, fsynced, then the two names exchanged in one step), so it is never torn; if an editor saved meanwhile, the exchange is undone, the save kept, and the capture refused. It deletes nothing, ever: after the exchange the temp name holds the displaced copy, which stays (a dotfile, gitignored) until `kgme clean kept` finds its bytes still the ones the capture recorded in its `kept` ledger note; a copy that differs holds a save the file lacks, and every later capture into that file refuses, naming it, until Michou merges it by hand.

**Transaction.** One `intent` before the write, naming the destination, the offset and size of the line added (or `new`), and the sha256 of the bytes, and for a replace of the whole file as read and as intended; one `outcome` after. A refusal is one `intent` and one `refused` outcome of class `blocking`, the words in its summary so nothing he said is lost. One run at a time over the vault (`kgme-vault.lock` in the git directory, shared with `kgme daily`); on start, an intent without an outcome is read against its file (`kgme/capture_recover.py`): closed `ok` when the file holds the intended bytes and its kept copy, if any, the bytes it was read as; `transient` when the file still holds the bytes it was read as and its kept copy, if any, the capture's own (or a new note is absent); and anything else stops the run naming the file. A failure after the write is settled the same way before it is closed. The same kind, words, due, and day are one capture: a retry or a duplicate run writes nothing and says "already captured". `--dry-run` prints what would be written and writes nothing.

**Manifest.** `manifest.toml` beside this file: read `memory/templates`, `memory/notes`, the friction log, `memory/daily`; write `memory/notes`, the friction log, `memory/daily`; no network.
