# Handoff 0021 — Install Homebrew from a pinned, fully inspected installer

Reissued by Cowork from proposal 0008 after Codex's review (AUDIT-0004): pinned revision, full inspection, interactive sudo, scratch dir not `~/Downloads`, minimal profile edit, analytics off.

**Who types what:** Claude Code does steps 1–3, 5 and 6 (no password involved). Step 4 — running the installer — is Michou's, in his own terminal tab, because the installer asks for his password and Claude Code must never handle it.

## Steps
1. Scratch: `mkdir -p ~/.kgme/quarantine/brew-install` (never `~/Downloads`).
2. Pin: resolve the current commit of `Homebrew/install` via `curl -fsSL https://api.github.com/repos/Homebrew/install/commits/HEAD` and record the `sha`. Download **at that commit**: `curl -fsSL https://raw.githubusercontent.com/Homebrew/install/<sha>/install.sh -o ~/.kgme/quarantine/brew-install/install.sh`. Record `shasum -a 256` of the file.
3. Inspect the whole script (it is ~1,000 lines; read all of it, not 40). Report to Michou, before running: every path it writes (`/opt/homebrew`, `/etc/paths.d/homebrew`, anything under `~`), every `sudo` and `chown`/`chmod -R` it performs, and whether it needs Xcode Command Line Tools (present per AUDIT-0001). Wait for approval.
4. **Michou, in his own terminal tab:** `bash ~/.kgme/quarantine/brew-install/install.sh` — with **no** `NONINTERACTIVE`, so the installer prompts him for his password itself. He says "done" when it finishes; Claude Code continues.
5. Shell profile: `cp ~/.zprofile ~/.zprofile.bak.$(date +%Y%m%d)` if it exists (create it if absent); show the one-line diff adding `eval "$(/opt/homebrew/bin/brew shellenv)"`; apply on approval. Do **not** `source ~/.zprofile`; verify in a fresh shell instead.
6. `brew analytics off` (privacy default per charter §3.5). Record `brew --version`, `brew doctor` output summary, and Homebrew's own revision: `git -C "$(brew --repository)" rev-parse HEAD`.

## Reversibility
Homebrew's uninstall script (pin it the same way at the time) removes `/opt/homebrew`; `/etc/paths.d/homebrew` and the `~/.zprofile` line are removed by hand; ownership changes under `/opt/homebrew` are moot once the directory is gone. This is documented restoration, not exact restoration — say so in the report.
