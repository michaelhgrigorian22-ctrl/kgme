# Handoff 0026 (proposed) — The ledger, ADR-019, and the vendor-stream fixture test

## Why
The ledger is the one durable class (ADR-012) and the artefact every later step records into: hooks, canaries, `kgme clean`, `kgme brief`, the cockpit. All four reviewers in AUDIT-0011 made it the first code. The event shape is fixed by ADR-019 (proposed 2026-09-14), which Michou accepts before or with this handoff. Ships with 0025 as one foundation release, two commits.

## What
1. `kgme/ulid.py`: `new_ulid() -> str`, monotonic within a process, `os.urandom`, about twenty lines.
2. `kgme/events.py` (pure): `make_event(**fields) -> dict` filling defaults and `ts`; `validate_event(event) -> None` enforcing the ADR-019 field set and enums; `redact(text) -> str` with the ADR-008 patterns; `parse_claude_stream(lines) -> list[dict]` and `parse_codex_exec(lines) -> list[dict]` mapping the two vendor formats into v1 events with `kind: tool_call` (Phase 2 will call these live; Phase 1 only tests them).
3. `kgme/ledger.py` (effects): `append(event) -> str`, `read(since=None, run_id=None, stream="both") -> list[dict]`, `open_intents(job) -> list[dict]`. Append per ADR-019 §4: validate (including the nullable `parent` field), redact `summary`, refuse over 4096 bytes, select the stream by the ADR-019 §2 rule (read-only tool hook pairs to `logs/trace/`, everything else to `logs/ledger/`; a refused call always to the ledger), month from the event's own local `ts`, `O_APPEND` + `flock` + one `os.write` + `fsync`. The caller never names the stream.
4. `logs/ledger/` created with a `README.md` (schema pointer, never-delete notice); `logs/trace/` created with a one-line README (untracked, deletable, read-only tool events); `logs/ledger-test/`, `logs/trace-test/`, and `logs/scratch/payloads/` created empty and gitignored.
5. `tests/test_ledger.py`, `tests/test_events.py`, and two recorded fixtures: `tests/fixtures/claude-stream.jsonl` (one real `claude -p --output-format stream-json` run of a trivial prompt, secrets absent by construction) and `tests/fixtures/codex-exec.jsonl` (one real `codex exec --json` run). Michou's addition 2026-09-14: a fixture test, not a feature.

## Outputs
`kgme/ulid.py`, `kgme/events.py`, `kgme/ledger.py`, `logs/ledger/README.md`, `tests/test_ledger.py`, `tests/test_events.py`, `tests/fixtures/claude-stream.jsonl`, `tests/fixtures/codex-exec.jsonl`; `docs/adr/ADR-019-ledger-event-schema.md` flips `status: proposed` to `accepted` on Michou's word (his edit or his instruction, recorded).

## Acceptance test (under two minutes)
1,000 events appended from four concurrent processes into `logs/ledger-test/` give 1,000 parseable lines with unique ids and no interleaving; a `tool:Read` intent/outcome pair lands in `logs/trace-test/` and a `tool:Edit` pair in `logs/ledger-test/`; a refused `tool:Read` lands in the ledger; `read(stream="both")` merges the two in `id` order; an event with `parent` set to an unknown id is accepted and flagged by `read` as an orphan; a mocked clock at 2026-09-30T23:59:59.900-07:00 and 2026-10-01T00:00:00.100-07:00 writes to two month files; a 5,000-byte line is refused with an exception, not truncated; a summary containing `token=abc123DEF456ghi789` is redacted before it reaches disk; `open_intents("x")` returns exactly the one intent lacking an outcome; both vendor fixtures parse into valid v1 events. `git status` is clean after the test run.
