# Handoff 0037 (proposed) — Cockpit v0: the read-only timeline

## Why
The roadmap's Phase 1 exit test: the timeline shows a real run. Michou ruled 2026-09-14 that v0 is a read-only timeline over the ledger and nothing else; live ingestion of vendor streams, approvals, the side lane, dispatch, and VS Code follow are Phase 2 (roadmap line 20, ADR-017 §Build order). The hook events from his own Claude Code sessions are the real runs it shows.

## What
1. `cockpit/server.py` (effects): `http.server.ThreadingHTTPServer` bound to `127.0.0.1` on the port from `kgme.toml` (default 8642). Routes: `GET /` (the page), `GET /api/events?since=<ulid>&limit=<n>&stream=both|ledger|trace` (through `ledger.read`, default both), `GET /manifest.json`, `GET /icon.png`. Any other method or path returns 404. No route mutates state or launches a process.
2. `cockpit/render.py` (pure): event grouping by `run_id`, intent/outcome pairing by `ref`, nesting by `parent`, unmatched-intent detection; trace events collapsed under their parent by default and expanded on a keystroke.
3. `cockpit/index.html` with inline CSS and JS: polls `/api/events` every two seconds, renders the approved design's five states, keyboard map as approved, escapes all event text, loads no remote asset.
4. `cockpit/manifest.json` and `cockpit/icon.png` so Chrome "Install page as app" and Safari "Add to Dock" work. The docstring and the README state that the Dock icon does not start the server; `kgme cockpit` starts it by hand, because launchd waits for Phase 3.
5. `docs/readers/cockpit.md`: how to start, install to the Dock, and read the timeline.

**Amendment (2026-10-21, Cowork; HANDOFF-0055).** Built from the files at the commit named by Michou's newest `canvas` approval (`kgme approve --show canvas`), never from a later one. One contract between the two sides: the design's sample events (`docs/design/cockpit-v0/station/sample-events.jsonl`) are validated by the ledger's schema validator in `make check`; the run lifecycle (working, waiting, transient, blocked, quiet), written today in the station prototype's script, becomes one pure function in `cockpit/render.py`, tested against those same sample events, and the page displays what `/api/events` returns from it rather than deciding states itself.
