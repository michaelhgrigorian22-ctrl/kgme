# Lessons — the design track (read at the start of every CDH; 40 lines max, condense rather than append)
This file lives under `docs/readers/` because schema v1.4 lets a note live only there, in `docs/` itself, `docs/plans/` or the vault (`kgme/schema.py` FOLDERS); `docs/handoff/cockpit-design/` admits handoffs and its `README.md`. The per-skill `lessons.md` path ADR-023 names needs a one-line exemption in `kgme/vault.py` beside README's — the substantive track's call.

Delivery and evidence
- `device_commit_files` with a stagedPath used before can send the stale upload. Every report and design file goes out from a fresh path, and its sha is checked on the Mac before the commit. Bitten twice (AUDIT-CDH-0013 F4).
- Capture hashes are taken on the Mac after delivery, never on the VM. PNGs from headless Chromium are not re-encoded; JPEGs from the browser pane are what the pane gives. A SwiftShader screenshot takes seconds; at ×20 that is minutes of replay. Evaluate the check first, screenshot second, and record the replay clock before and after each capture. For a precise moment, load with `?at=HH:MM:SS&speed=2`.
- A synthetic sample used for a check is labelled, kept under `logs/scratch/design-review/<cdh>/`, validated with `kgme.events.validate_event`, and never committed to the design folder.

The canvas editor and the pane
- `<dc-import name="X" prop="{{val}}">` mounts sibling `X.dc.html`; a child's `<helmet>` CSS applies in the parent, so prefix its classes; it may mount twice on one board.
- Toggling a board's Tweak makes the editor re-save that file (attribute quoting only). Diff against the repository before republishing the review copy.
- Screenshots work with the pane hidden, but after a load the artifact frame paints only on a later capture, sometimes the third: keep capturing every 10 s until it does. The pane's width follows the side panel (643 CSS px once); read the frame's width from the host page before judging a layout. The Tweaks icon needs the pointer tool, not the hand. Zoom from the menu, pan with wheel ticks (~87 px each); a drag flings. `#artboard-<id>` appears in the hash once a board is selected.
- After a click inside it, the artifact frame takes keys from the pane too (Tab, Shift+Tab, Enter on board 7, 2026-10-22), but it does not expose its accessibility tree: names are measured standalone; clicks, keys, focus rings and pixels natively. A capture can trail the last action by one step.
- A hidden tab pauses rAF; cap the per-frame delta or the first frame back jumps a replay past its end (CW15's cause). Orthographic depth alone gives no parallax: use distinct camera-pan coefficients and verify screen displacement; let camera easing settle before measuring twinkle (CDH-0029). A background in an unbounded camera must cover the viewport and wrap its stars; finite planes expose straight edges under pan. Verify actual minimum zoom and repeated drags (CDH-0029 follow-up). For a moving decorative shell, compare frozen pixels under fixed scene lights: a timed event light can change even while replay is paused (station casino).

Measurement
- Contrast uses linearized sRGB, (L1+.05)/(L2+.05), after any CSS filter. Audit every actual cell's cascade: a muted class cannot override inline color, even when color follows another declaration. CDH-0017 missed duration cells; CDH-0019 verified the repair with computed styles. For a 3D background, sample pixels with text fill masked (not color, which changes currentColor borders), pause periodic word updates during capture, and keep decorative frame glow below the words (CDH-0028). Contrast is a composited pixel, not a CSS pair: overlays above the words and the renderer's text gamma take a 4.59 pair to 4.47, so a text token needs headroom (4.8 by the pair) and every overlay sits below the text layer (CDH-0030). Swatch wrappers can reflow anonymous grid text: compare every final range with its original, then measure affected glyphs by node identity, never repeated wording; Safari white-fill saturation extends beyond the coloured glyph core, so erode that mask before measuring (CDH-0032). A three-pixel sample stride aliases a three-pixel scanline; sample opaque glyph cores across every background phase. Maximum white-minus-background signal selects the darkest background, not all opaque cores; use normalized coverage and retain exact node/clipping ownership (CDH-0031).
- A fixed grid minimum can exceed a phone's inner width. Cap it to 100% of available width and measure both sides of the media breakpoint plus desktop widths; CDH-0019's 7-width fixture preserved the wide layout.
- Chromium joins a button's inline spans without spaces when it names it from content; give dense rows an explicit, complete `aria-label`. The visually hidden status region's clipped text box runs past the viewport; leave `.vh` out of overflow measurements. An opaque phone HUD can hide real Tab targets. Check every focused room and the opened pane against the current HUD bounds; following a room changes wrapping and therefore those bounds (CDH-0022 / CDH-0019 cycle 2). A fix applied in the render loop shows on the next frame: measure after rendered frames (rAF), not a fixed delay. An emulated reduced-motion change does not always fire the matchMedia listener; poll once a second as well.
- A Safari window under WebDriver shows an "automated session" banner and ignores a human's mouse and keys; don't judge a page from it. No WebKit exists off the Mac: Safari checks are Codex's through `safaridriver`, and a Cowork review repeats the contrast half in Chromium, which paints the same (CDH-0030).
- A zero-specificity reset (`:where(button)`) keeps component rules in charge; a leaf class must differ from the root class derived from its view (CDH-0026); `.tr-root :where(button)` is still (0,1,0).
- A legacy state sentinel is not an event count. Separate state from count, label missing counts explicitly, and exclude them from numeric peaks and totals (CDH-0025; Michou confirmed). When a fact moves, check its value as well as its presence (CW31). A line added to an anchored label widens it: measure label-to-label overlaps at a mid width (800 × 600) too, not only the phone and the design width (CW34).

The loop
- Codex commits its own three delivery files and takes the next ready row; Cowork applies blocking findings as the next cycle and Michou vetoes after the fact (2026-10-14 00:41). Under ADR-023, checks are run, not asked; judgement calls are scored (stakes × edge ≥ 1.5 asks, batched, with a recommendation) and the scores recorded in the README's open list.
- Start from a `ready` row and committed sha; coordinate ownership of every file being staged. Handoff bodies belong to their author: report broken references for the author to correct, never edit the instruction body (CDH-0019, ebcb847).
- Git from the VM: `GIT_DIR=$HOME/mnt/KGME/brain/.git/worktrees/Automate-design GIT_WORK_TREE=$HOME/mnt/KGME/design` (the home is `~/Projects/KGME` since HANDOFF-0049; the worktree's metadata keeps its old name), `-c core.hooksPath=/dev/null -c gc.auto=0`; the VM cannot delete in the Mac's folders, so an auto-gc leaves `HEAD.lock` behind — move it aside under `.git`, never delete it.
- From 2026-10-16 (CDH-0019) Codex builds and reviews in one always-on session; Cowork reviews its builds natively and publishes the artifacts; new work still enters as a `ready` row written by Cowork or Michou, and the merge of `main` into `design` is a builder's task, rehearsed first in a clone.
- Use an absolute uv-cache path inside the worktree: test hooks change directory and a relative cache resolves inside each fixture; seed the locked cached wheels for offline runs (CDH-0032). The one quiet threshold reproduces the boards' drawn samples; a rule that contradicts a drawn sample is wrong, not the sample.
