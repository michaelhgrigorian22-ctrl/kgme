Keyboard map

Solid cyan keys are bound in v0. Dashed keys are reserved for Phase 2 and do nothing yet; pressing one shows a one-line "Phase 2" notice and the key it is reserved for. Single-character keys act only while focus is on the cockpit's own surface and never inside a text field (the filter line takes text; there only Enter and Esc act); ? lists them, and remapping is Phase 2 (WCAG 2.1.4).
