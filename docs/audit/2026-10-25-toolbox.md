## Design decisions, each recorded
- **`held` says what the sha stands behind:**
  - a repository path, verified on every run;
  - a folder, for a skill, hashed as the sorted `<path> <sha256>` lines of its files, so any change, addition or removal shows;
  - `uv.lock`;
  - `pending: <path> (HANDOFF-NNNN)`;
  - `machine: <path>`, a harness or model as installed here, recorded and not verifiable from a clone.

  This answers "every row has a sha" for things KGME does not hold as files.
- **A skill row holds the folder,** not each file. Eleven files make four rows. `skills/kgme-*` are KGME's own and need no row.
- **The checks run in `cli.run_lint`, not `kgme/lint.py`.** `lint.py` is pure and the checks read files; amendment 10 put the checks in their own module.
- **The licence rule follows §3** (advisory under 1.7, blocking from the next line), where ADR-020's one-line summary says blocking; the ADR draft states the ramp.
- **Outputs widening:** `kgme/schema.py` (the `TOOLBOX` id) and `kgme/cli.py` (the call).

## Review cycle 1 (AUDIT-0122, BLOCK), fixed
Eight regressions, all red on the pre-fix module (`logs/scratch/handoff-0044/red-c1.txt`), green after:
- **F1:** the `<script src>` regex could match `data-src`, so a remote script carrying a local `data-src` passed. The source is now read through the standard library's HTML parser, and only the exact `src` attribute counts.
- **F2:** pages were found with `glob("*.html")`, so a nested page went unchecked. Now `rglob`.
- **F3:** a `held: uv.lock` row was never checked against the lock. Now each such row must name a package `uv.lock` pins, at the row's version, with an artifact hash. A missing lock is blocking.
- **F4:** a `held` path was joined and read without confinement. A held repository path must now be relative, contain no `..`, and lie under `cockpit/static/vendor/` or `skills/`. The path, and every member of a held folder, must be no symlink and resolve inside the repository. A refused path is blocking and never read. The test plants a file outside the repository and reaches for it five ways: an absolute path, a `..` path, a path outside the two folders, a vendored symlink, and a symlink inside a skill folder.
- **F5:** a missing licence was advisory forever. Its class now comes from the schema's `version`: advisory below 1.8, blocking from 1.8 and when the version cannot be read.
- **F6 (cosmetic):** the report's ADR-020 status is corrected, as above.

## Review cycle 2 (AUDIT-0123, BLOCK on F3 and F4), fixed
- **F3:** any non-empty lock hash passed, including the fixture's own `sha256:aa`. Every artifact hash of a locked package must now be `sha256:` and 64 lowercase hex digits, and there must be at least one. The fixture carries a real-shaped digest, and four malformed digests are refused.
- **F4:** a symlink in an *ancestor* folder was not checked. With `skills/alias -> memory/notes`, holding `skills/alias/example.md` passed and the file was hashed. Every component of a held path is now checked for a symlink before anything is traversed or read. The regression makes the target unreadable, so any read would raise.
