# HANDOFF-0037: cockpit v0, the read-only timeline (first half: the server and the view)

**This is half of the handoff.** It is the half that does not depend on the canvas: the view, the server, and `kgme cockpit`, reviewed and committed as one increment with the handoff still `open` (as HANDOFF-0047's follow-up was). The page, `cockpit/index.html`, together with `cockpit/manifest.json`, `cockpit/icon.png` and `docs/readers/cockpit.md`, follows as its own commit under this handoff. Per the amendment it is built from the files at the commit Michou's newest `canvas` approval names. No such approval exists yet. Cowork reads it from the ledger and names the commit once Michou records one.

## What was built
1. **`cockpit/render.py` (§2, pure).**
   - **Grouping and pairing:** events are grouped by `run_id`. An intent is paired with the outcome whose `ref` names it, and an intent that no outcome names is unmatched.
   - **Nesting:** events nest by `parent`, with a depth.
   - **Trace events** are collapsed under their parent until the page expands them.
   - **The run lifecycle** (working, waiting, transient, blocked, and quiet within working) and run closing are one pure function each, ported rule for rule from the station prototype's `lifecycle` and `runClosed`. The port is checked against the prototype itself: its JavaScript was extracted verbatim and run in Node over the design's 40 sample events at 51 clocks from 19:40 to 20:05. The two implementations agreed in all 267 comparisons, covering every word, quiet, and closed runs (`logs/scratch/handoff-0037/equivalence.py`). Seven of those answers are pinned in `tests/test_render.py`, so the test needs no Node.
   - **`build_view`** is what `/api/events` returns: the last `limit` events after `since` in id order, each tagged with its stream, pairing, depth and collapse; the state of every run they touch, computed over all the events read; and a cursor for the next poll.
2. **`cockpit/server.py` (§1).**
   - **Binding:** `ThreadingHTTPServer` on the host and port of `kgme.toml [cockpit]`, refused for any host that is not loopback.
   - **Routes:** `GET /` (the page, 404 until it exists), `GET /api/events?since=&limit=&stream=` (a bad value is 400), `GET /manifest.json`, `GET /icon.png`. Every other path, and every method but GET (an invented one included), is 404.
   - **Read-only:** no route writes or launches anything. Responses carry `no-store` and `nosniff`.
3. **`kgme cockpit`** wired in `kgme/cli.py`. It serves until interrupted. Run against the real ledger, it served this session's own events, with the run shown `waiting` while a tool call's intent awaited its outcome.
4. **The amendment's contract:** the design's sample events pass `kgme.events.validate_event` in `make check` (`test_the_design_sample_events_pass_the_ledger_validator`).
