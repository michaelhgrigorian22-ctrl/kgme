### Two rules decided while building
- **A plan with one refusal deletes nothing.** ADR-016 stops a job on a blocking finding; a deleter that continued past a refused path would leave a half-cleaned target and a refusal the operator might not read. The refusals are written as `refused` outcomes under the plan's `intent`, the exit code is 1, and the operator removes the offending entry by hand.
- **The `.git` rule names the directory.** The handoff says "any path containing `.git`"; the first reading (any part starting with `.git`) refused `.ruff_cache/.gitignore` and `.pytest_cache/.gitignore`, which ruff and pytest write into their own caches, and with the rule above the `caches` target could never run. The rule is a path part equal to `.git`, the object store it exists to protect; the live dry run below shows the difference.
