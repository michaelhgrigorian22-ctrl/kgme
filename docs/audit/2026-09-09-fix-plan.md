# Fix plan — from AUDIT-0001, per Phase 0 §3 and ADR-008

Seven proposed handoffs (`HANDOFF-0006` through `HANDOFF-0012`), all `status: proposed` under `docs/handoff/proposed/`. None will run until Michou flips a proposal to `status: open` or asks explicitly. Numbering continues from 0006 because HANDOFF-0004 (global Claude config audit) and HANDOFF-0005 (git identity) already claim 0004 and 0005 in the accepted handoff sequence.

## Recommended run order

1. **HANDOFF-0006 — Time Machine destination.** *Do first: no reversibility guarantee exists for anything outside git today; ADR-008 assumes backups.* Needs Michou physically present with a disk and sudo, so it should anchor the session that also runs 0010 and 0011.
2. **HANDOFF-0010 — SSH key for GitHub.** *Bundle with the same physical session as 0006.* Passphrase requires Michou present; unblocks Phase 0 §7 GitHub remote setup and is safe to do in parallel with a running Time Machine first backup.
3. **HANDOFF-0007 — Enable application firewall.** *Cheap, small blast radius.* Also in the same physical session as 0006/0010; needs sudo but is a one-liner.
4. **HANDOFF-0008 — Install Homebrew.** *Prerequisite for 0009 and any later tool install.* Can run in the same session; needs sudo and Michou approval to run the downloaded install script.
5. **HANDOFF-0009 — Install `gh` via Homebrew.** *Immediately after 0008.* No sudo; needed for Phase 0 §7 GitHub work.
6. **HANDOFF-0011 — Rename paths with spaces under `~/Projects`.** *Highest care required.* Do only after Michou has flagged which Finance workbooks have live external links. Personal is safe first; Finance last.
7. **HANDOFF-0012 — `pmset` heartbeat decision.** *Deferred.* Phase 0 §4 requires two weeks of friction-log observation before deciding A/B/C; this proposal exists so the decision is on the record, not to run soon.

Order rationale in one line each: 0006 (safety ground) → 0010 (passphrase requires presence, bundle) → 0007 (quick security win, bundle) → 0008 (unlocks tooling) → 0009 (needs 0008) → 0011 (highest breakage risk, wait for reference audit) → 0012 (needs two-week observation).

## Judged NOT worth a proposal (with reason)

Following the handoff rule ("Do not propose anything the audit did not surface" and "do not propose installing Playwright, Ollama models, or Chrome profiles — those are separate designed steps"), these audit items are surfaced but *not* turned into proposed handoffs:

- **Three parallel Python installs (audit finding 8).** `uv` is present, which is the Phase 0 §3 requirement. Removing the other Pythons is not needed; documenting the "leave alone, use `uv` only inside KGME" posture is a documentation change in `CLAUDE.md`, which ADR-011 marks as Cowork-owned. Belongs in a doc update, not a machine handoff.
- **Codex CLI not installed (audit finding 10).** Not on Phase 0 §3; not on ADR-008. The AGENTS.md symlink created by HANDOFF-0002 is dormant until Codex ships. Wait for a designed Codex-install decision.
- **Password manager CLI (`op` / `bw`) not installed (audit finding G).** ADR-008 mentions 1Password "if in use"; Michou is not currently using one. Tool choice belongs to Michou (Phase 0 §7 puts "password manager + CLI" on his own list). A proposal to install `op` presupposes 1Password as the tool — premature.
- **Global `~/.claude/CLAUDE.md`, `~/.claude/settings.json` (permissions, hooks), Cowork agents / commands, loose `~/AGENTS.md` at `$HOME` (audit finding 7 and AUDIT-0002 sections 1–5).** AUDIT-0002 already lists the reconciliation options. All of these are Cowork-owned edits (to `CLAUDE.md`, to `~/.claude/settings.json`, or to global agents), not machine tasks for claude-code to run.
- **Avast antivirus running (audit finding 11).** No ADR or plan requires removal; leave alone. Note only.
- **Stray `~/AGENTS.md` at `$HOME` (audit finding 12; AUDIT-0002 §4).** Dormant until Codex ships; the fix belongs bundled with a future Codex install, not standalone.
- **Ollama has zero models pulled (audit finding 15).** Phase 0 §5 designed step; explicitly excluded from HANDOFF-0003 scope.
- **Playwright not installed.** Explicitly excluded from HANDOFF-0003 scope.
- **Chrome profiles / KGME profile creation.** Phase 0 §7 (Accounts) territory; explicitly excluded from HANDOFF-0003 scope.
- **No git repositories under `~/Projects` at depth 3 (audit finding 13).** HANDOFF-0002 created the first one; the audit finding is now stale, not a gap.
- **Claude Desktop MCP servers = 0 (audit finding 14).** A *good* state (nothing to reconcile). No action.
