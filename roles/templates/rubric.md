# Rubric: {id}

Scored on the run's trace in the ledger, not only on its output (ADR-025 §4). Three to six
dimensions; a `(gate)` fails the run whatever else scored. The department adds its own.

## Dimensions
- `intent` (gate): the end matches the goal the run stated first.
- `context` (gate): the run read what the task needed before acting.
- `scope`: the run did the task and nothing beside it.
